# 北京 v4 · B 部分:拥堵内生性(路网级一阶拥堵模型)

(2026-06-08。记录 paper B 的 B 部分:从出行选择(A)到路网拥堵的供给侧建模与疏解反事实。
A 部分见 [02_model_construction] / [04_gnn_rum_boundary],可达性 equity 见 accessibility_equity.py。)

## 0. 一句话核心

**拥堵是均衡结果——它由个体出行选择(A)压到路网上产生,反过来改通勤时间、再影响选择。
B 部分把这个闭环的供给侧(路网分配 + 拥堵函数)建出来,使"疏解政策→拥堵怎么变、可达性怎么变"可算。
当前实现 = 路网级【一阶】拥堵模型(自由流分配 + BPR),足以支撑反事实方向;完整用户均衡/可微分留作精修。**

## 1. 为什么是路网级(不是 cell 级)

用户选路网级:链路级精确拥堵。代价是要一个可路由、带容量的网络。
- ⚠ 原始道路中心线 SHP(114万段)naive 端点吸附**建不出连通网络**(连通 61%、路由相关 0.07,验证否决);
- 改用 **OSMnx** 拉北京主干驾驶路网(motorway..tertiary + ramps):**49,835 节点 / 105,402 链路,100% 连通**,
  自由流路由 vs 观测 t_ff 相关 **0.65** → 可用。容量/自由流速按 highway type 配。

## 2. 管线(B1→B2→B5)

| 阶段 | 做法 | 产物 |
|---|---|---|
| **B1 网络** | OSMnx 主干路网 → 节点-链路(自由流时间+容量)→ cell 接最近节点 | `beijing_road_network.npz` |
| **B2 分配+拥堵** | 车 OD(人流×车分担 by 距离档)聚节点 → **自由流全有全无分配**(每起点 dijkstra+子树级联)→ 链路流 V → V/C(需求缩放到中位 0.6)→ **BPR** t=t_ff(1+α(V/C)^β),封顶防爆 | `beijing_assign_p*.npz` |
| **B5 反事实** | 疏解(通州+30万岗位/核心-20%)→ **结构引力**重算 OD 流量(与可达性一致、可外推)→ 重分配 → 拥堵变化;并把新拥堵反馈进 OD 时间 → **GE 可达性** | `beijing_congest_scenario_p0.npz` |

- **为何用结构引力(非全 NN)做反事实流量**:外推用结构部分才可信(见 [04_gnn_rum_boundary] 的内插/外推边界);
  且与 Hansen 可达性同一形式,前后一致。
- **为何自由流 AON 而非完整 UE**:zone 聚合的 MSA-UE 出现 zone 装载节点人工瓶颈(V/C 爆、相关性掉到 0.18);
  节点级自由流 AON 反而最好(自由流流量=拥堵潜势)。完整 UE 留作精修。

## 3. 验证

| 判据 | 结果 |
|---|---|
| 网络可路由 | 100% 连通;自由流路由 vs t_ff corr **0.65** |
| 拥堵 vs 实测(dynamic_cong) | cell V/C vs 实测拥堵率 Pearson **0.349** / Spearman **0.437**(n=6052) |
| 行为合理性(疏解) | 拥堵**从核心搬到通州**:通州 V/C +14.2% / 核心 -4.4% / 全市 +0.2%(重分布不减总量)= 多中心疏解经典结论,模型自发给出 |

## 4. 反事实发现

1. **疏解不减拥堵、反而微升(职住失衡)**:空间上拥堵从核心搬向通州+周边(朝阳/大兴),全市 V/C 均值几乎不变(+0.2%);**但系统总账是亏的 —— 总拥堵延误 +1.24%、总通勤时间 +1.16%**。机理:只搬岗位、人仍住中心 → 去通州上班的通勤拉长 → 新增出行+通州走廊拥堵盖过核心减堵。**硬结论:单疏岗位 backfire,要减拥堵须"岗位+住房"一起搬。** (方向机理稳健;幅度受一阶模型/BPR标定影响,别当精确。)
2. **两个渠道(GE 揭示,A 单独看不到)**:疏解改善可达性有两条路 ——
   - **岗位搬迁**(帮蓝领/通州:生产 partial +7.9%,主导);
   - **核心减堵**(帮白领/高收入:专技 partial +0.2% vs 减堵 +1.1pp、高收入 +1.0% vs +1.0pp → **白领/高收入受益主要靠核心减堵,不是新岗位**)。
   → **B(拥堵耦合)的价值正在此:不耦合就会漏掉"白领/高收入主要靠核心减堵受益"这条。**
   (延误已标定到实测 t_obs/t_ff 中位 1.16×/封顶 2.9× 后,GE 反馈 ~1pp 是可信幅度;方向对所有标定稳健。)

## 5. 诚实边界(必须写)

- **一阶模型**:自由流全有全无分配,**无拥堵下重路由、无完整用户均衡** → 捕捉一阶量变(需求变→流量变→拥堵变),二阶(均衡再分配)未含;
- **拥堵延误已标定**:延误封顶 = 实测 t_obs/t_ff 上限(中位 1.16× / 90分位 1.51× / 封顶 2.9×),GE 反馈 ~1pp 可信;但 BPR α/β 仍是标准值未精估,幅度对其敏感;
- **拥堵实测**单日快照(dynamic_cong)、只主干路 → corr~0.35-0.44 是这套数据下的合理上限;
- **B4 可微分分配 + 供给-需求识别 β_t** 未做(研究级,为标定/识别,不挡政策方向)。

## 6. 与 A 的关系 + paper 定位

> A(选择模型)= 需求侧:谁去哪、可达性。B(本部分)= 供给侧:流量压到路网→拥堵→反馈通勤时间。
> 两者闭合给出**完整政策反事实**:疏解 → ①各群体可达性不平等怎么变(职业/收入)②拥堵怎么重分布。
> **核心贡献(B)**:把可信选择模型的反事实从"谁去哪"推进到"路网拥堵 + 一般均衡可达性",并揭示岗位/减堵双渠道的群体异质受益。
