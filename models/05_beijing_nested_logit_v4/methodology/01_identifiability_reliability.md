# 北京 v4:行为参数可识别性与 reliability 方法学

(2026-06-05 整理。对应 Paper B / Beijing 模型线。本文记录"为什么模型的 mode 选择与
occupation 匹配可信"的完整论证链,是 reliability 的核心章节。)

## 1. 问题:聚合通勤 OD 欠识别两个核心行为参数

模型的目的地选择头里有两个行为参数承担可解释性与反事实可信度:
- **mode(出行方式)**:车/公交/步行的选择,经嵌套 logit 的 inclusive value 进入目的地效用。
- **occupation 匹配**:工作者是否偏好"匹配自己职业的岗位"所在的目的地(δ_match)。

北京手机信令 OD(`od_cell_flow`, 16907 格 × 4 时段)是**方式合并、职业盲**的——只记"多少人 A→B",
不记"谁(什么职业)坐什么方式"。这导致两个参数**从聚合 OD 无法点估**。

### 诊断证据:严谨 profile likelihood(重新优化其他参数)
固定目标参数扫值、其余参数重训,看目的地 NLL 是否仍有曲率(= 可识别):

| 参数 | OD-NLL span(重训其他后) | 判定 |
|---|---|---|
| mode `asc_transit` | 0.035(对应 P(transit) 0.01~0.82 都给同样拟合) | 不可识别 |
| occupation `delta_match` | 0.00004(δ 取 0~8 OD 拟合零变) | 不可识别(更彻底) |

> ⚠ 方法学教训:用"固定其他参数"的 profile 会**高估**识别性(曾误判 mode 可识别);
> 必须**重新优化其他参数**,让它们补偿,才看真识别性。

**两个参数都被聚合 OD 欠识别。** 这不是 bug,是聚合数据的固有信息缺失(ecological)。

## 2. 解法总纲:外部带标签数据 + 重参数化

聚合 OD 缺的是"标签"(per-trip 的方式 / 职业)。解法是从**外部带标签数据**注入识别信息
(Ben-Akiva & Morikawa 1990 联合估计 / combined estimation 的精神),而非在聚合数据里硬抠。

| 参数 | 缺的标签 | 外部数据 | 机制 |
|---|---|---|---|
| mode | 每趟坐什么 | 公交刷卡(transit 真实 OD)+ 北京交通发展年报/2015微观(方式分担) | 矩匹配:去向模式 + 份额水平 |
| occupation | 谁去哪上班 | 2015 1% 人口微观(职业×工作地)+ 经普行业(职业岗位) | 重参数化 typed-mass + 标定 |

## 3. mode:双锚联合估计

**问题分解**:刷卡只有公交(无分母),定不了"份额水平";年报/微观有整体方式分担,定不了"空间去向"。两者互补:
- **去向锚**:公交刷卡 10.6M 出行 → 格子级 transit OD(含地铁)。模型预测的公交流量分布对齐刷卡 transit OD 分布(CE)。
- **份额锚**:北京真实通勤方式分担(2015 1% 微观个体 M61:车 0.21 / 公交 0.35 / 步+自行车 0.44)。模型流量加权方式份额对齐此目标(CE)。

实现:`--anchor-transit --anchor-share`,锚在 2M 边采样上算(脱离全局归一,兼容 origin-chunking → 任意 GPU)。

**结果**:全量 3-seed,**mode split [0.21/0.35/0.44] 全部锚到真实值**(s0[.214/.352/.435]/s1[.217/.347/.435]/s2[.212/.347/.441])。
mode 从"识别不出/随初值漂"变为"数据锚定到真实通勤分担"。

## 4. occupation:typed-mass 重参数化 + finer-geo,与诚实的二阶结论

### 4.1 重参数化:引力作用在"本职业岗位"
不把 occupation 当总引力之上的独立旋钮 δ(聚合 OD 识别不出 + 把所有岗位混成一个总数),
而是让引力直接作用在**本职业的岗位** M_j^o = 总岗位 × 该地职业需求占比:

  V_dest(职业 o) = γ · log(M_j^o) + α·log W_j + ν·log D_j + λ·IV

微观个体数据(2015 1% 跨区通勤者)上的条件 logit 验证 **δ ≈ γ**(0.86 vs 0.99,
"typed-mass 单系数"比"总引力 + δ 修正"少一参数、拟合一样),即数据支持该重参数化。
**δ 的识别难题在此 formulation 下消失**:occupation 经"哪些岗算你的"进入,由外部行业→职业桥标定。

### 4.2 finer-geo:让 M_j^o 表达职业集聚
- **2008 经普**(24 万企业,街道 + 行业)→ 街道级行业 → 分配到格子 → cell 级行业构成。
  - ⚠ 2008 用 GB/T 4754-**2002**,与 2011 版同字母含义不同(F/G/H/I);按**语义**对齐(经业务文字反推校准),非字母位置。
- **2023 AOI** 校准:补 2008 缺的 post-2008 集聚(望京办公 信息业 0.027→0.049 翻倍);AOI 稀疏故影响有限(L1 0.086)。
- 结果:cell 级职业需求 **海淀(中关村)专技 0.40 > 朝阳(望京)0.32 > 大兴(亦庄)0.24(生产运输 0.32)** —— 真实职业集聚被捕获。

### 4.3 诚实结论:occupation 匹配是二阶效应(金标准实证)
2015 微观(职业×居住区×工作区,北京就业 9938 人)直接测:
- 不控居住时,各职业"工作区分布"相关 0.376(看着不同);
- **控制居住区后相关 0.976**(几乎相同)→ 那 0.376 几乎全是**居住分选**(不同职业住不同区 + 就近上班),
  职业本身不独立预测去向。条件 logit 估 δ=0.86 但加 δ 的对数似然增益仅 0.6%(统计显著、经济二阶)。
- 细到职业中类无增益:**天花板是工作地地理分辨率(微观工作地只到区/县)**,不是职业不够细。

> 即:北京 occupation 匹配真实存在(蓝领→亦庄工业 / 白领→中关村·金融街),但是**二阶**;
> 引力(住哪 + 岗位在哪)是主力。模型把它建成"按职业的岗位引力 γ≈0.98"是正确且可解释的。

## 5. 全量结果:完整识别模型,零 CPC 代价

RTX 4090(24GB,origin-chunks=16),完整模型 = mode 双锚 + typed-mass occupation + NN(residual)+ 词典筛选 + soc 混合:

| | CPC(3-seed) | mode split | 说明 |
|---|---|---|---|
| 无锚无 typed(基线) | 0.6925 | 不可信(随初值) | — |
| **完整识别模型** | **0.6926 ± 0.0083** | **[0.21/0.35/0.44] 锚定** | **mode 识别 + occupation typed-mass 零代价** |

即:把两个"致命"行为参数都做成数据锚定、可解释的形式,**CPC 一点没掉**。这是 reliability 的关键——
可信度的提升不以拟合为代价。

## 6. 诚实的数据边界(限制章节)

- **公交时间**:刷卡实测速度标定(13.4 km/h,含地铁),非逐对路由;
- **occupation 工作地**:微观只到区/县级 → 区级下匹配二阶;亚区级集聚(中关村等)由 finer-geo **标定**(2008 + AOI),非聚合 OD 验证;
- **时效**:2008 经普行业(AOI 部分补 2023)、2015 微观 vs 模型 2023 信令,有时间差;
- **occupation 供给侧(居民职业)**只有区级(普查抽样 + 隐私上限),无街道级。

这些边界是数据受限环境(北京红线)下诚实建模的一部分,本身构成方法论贡献:
**聚合 OD 能识别什么、什么外部数据救什么、哪里只能标定 + 区间。**
