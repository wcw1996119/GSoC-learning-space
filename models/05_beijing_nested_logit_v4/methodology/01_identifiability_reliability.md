# 北京 v4:行为参数可识别性与 reliability 方法学(完整版)

(2026-06-06 重写,补全 2026-06-05 初版。对应 Paper B / Beijing 模型线。
本文记录"模型每一组参数从聚合通勤 OD 能不能识别、靠什么补"的完整论证链,是 reliability 的核心章节。
配套 [02_model_construction.md] = 模型具体怎么搭的。)

## 1. 核心:可识别性不是"mode/occupation 两个参数"的事,是整张参数表的一道光谱

模型(`beijing_model.py`)有一大把参数:方式下层(λ、β_t、asc、θ_inc)、目的地上层(γ_M、α_W、ν_D、δ 各按收入档)、
同格 boost(self_loop 16×4)、词典筛选三层(k/τ/budget/T_max)、NN 残差(w_nn + encoder)。
**它们被聚合 OD 识别的程度天差地别**:有的是 OD 流量直接钉死的(引力、通勤忍受度、同格占比),
有的只能靠外部数据锚(方式份额),有的彻底识别不出(职业匹配),中间还有一片"弱识别/共线"的灰带(收入档拆分)。

初版只写了最暗的两端(mode、occupation),漏了亮端和灰带。本版按光谱**全部铺开**。

判据一句话:**固定某参数到一个值、把其余参数全部重新优化,看目的地 NLL 还有没有曲率。**
有曲率(span 大)= 聚合 OD 识别得了(固到错值补不回来);span≈0 = 识别不了(随便取值拟合一样)。

## 1.5 空间单元与数据分辨率(精度错配 = 异质性天花板的根)

**建模空间单元**:**~1km 网格,16,907 格**(最近邻间距实测中位 972m,5–95 分位 777–990m);其中 **11,371 格**有候选集(均值 ~2674 目的地/格,覆盖 97.2%);行政落 **16 区**。

**各数据源原生分辨率(差别很大,正是后面识别性光谱的根)**:

| 数据 | 原生分辨率 | vs ~1km 格 | 怎么处理 |
|---|---|---|---|
| OD 流量(信令 7.06M 行 × 4 时段) | **格级** | = | 直接用(目标变量) |
| 出行时间(t_matrix 30.4M 对) | **格对级** | = | 直接用 |
| 岗位 / 居民(cell_index) | **格级** | = | 直接用(引力 M_j) |
| **职业**(occ_share_by_district) | **区级 16×7** | **粗 16×** | **广播到格** |
| **教育**(2015 普查) | **区级 16×3** | **粗 16×** | **广播到格** |
| 收入代理(安居客房价) | 小区**点级** 14,597 | 细 | 空间 join 到格 |
| 公交 | 线网几何 + 站点 | — | 自造 t_transit |
| 职业岗位面(finer-geo) | 2008 经普**街道级** + 2023 AOI | 街道级 | 拼 + 校准 → **格级 M_j^o** |
| 职业去向验证(2015 1% 微观) | 个体,工作地仅**区/县级** | — | 验证 δ=0.86,工作地分辨率 = 天花板 |

**三种处理**:① 格级直接用(OD/时间/岗位);② 区级属性**广播**(同区每格同值——职业/教育);③ 点级**空间 join**(房价);④ 职业岗位面用 **finer-geo 补到格级**(目的地侧),但 δ 验证只到区/县(出发地侧 + 工作地天花板)。

**⭐ 错配 = 异质性天花板的根**:出行 / OD / 岗位侧是**真 ~1km**,但"人是谁"(职业 / 教育)侧原生只有 **16 区** → 广播。这一条直接解释了后面三件事:
- 为什么异质性是"**区级构成的潜在混合**"而非个体级(§5.5);
- 为什么档间偏好参数(β_t / α_W)识别不出 —— **区内没有变化可学**(§5);
- 为什么职业"去哪"(目的地需求面)能靠 finer-geo 做到格级、但职业匹配"谁→哪"的验证停在区/县(§7)。

> 一句话:**行为侧高分辨率(1km)、人口属性侧低分辨率(16 区)**。这不是处理不当,是数据受限环境下的诚实上界——能补的(职业岗位面)用 finer-geo 补到格级,补不动的(区内个体差异)诚实写 limitation。

## 2. 诊断方法:严谨 profile likelihood(重新优化其余参数)

`experiments/profile_param_reopt.py`(通用)+ `profile_occ_reopt.py` / `profile_mode_reopt.py`(mode/occ 专版)。
对每个目标参数:固定它扫一组值,**其余参数每次从头重训**,记录 OD-NLL。在 1500 格 smoke 子集(168 万边)、
40 步 Adam,纯 RUM(不带 NN,gnn-mode=convex)上跑,保证不同参数**同一把尺子**可比。

> ⚠ 方法学教训:用"固定其他参数不动"的 profile 会**高估**识别性(曾误判 mode 可识别)。
> 必须**重新优化其余**,让它们尽量补偿,才看真识别性。

## 4. 亮端 🟢:聚合 OD 自己就能识别的(模型可信的主体)

这一档是 reliability 的**地基**,初版完全漏写,让模型显得"全靠外部锚"。其实大半结构是 OD 流量直接钉的:

- **γ_M 引力**(span **[g_mid]**,远大于 occupation 0.00004):流量随目的地岗位数的梯度直接写在 OD 里,
  固定 γ_M 到错值、重训其余补不回来 → 识别。三 seed 全量 γ_M≈[0.41/0.83/0.62](低/中/高),符号恒正。
- **T_max 通勤忍受度**(span **[tmax_mid]**):流量随距离/时间的**截断**在 OD 里看得见。
  三 seed 学到 [39/63/93] 分钟,抖动 < 1 分钟,比例 1:1.6:2.4 对齐 Bhat 1995 的 1:1.8:2.5。
- **self_loop 同格 boost**(span **[selfloop]**):OD 的**对角线**(同格通勤)直接钉它。
  观测自连边占比 23.7%,模型预测 23.6–23.9%,几乎重合 → 这 64 个参数干净识别。
- **聚合距离衰减**:流量随距离整体衰减是 OD 最强信号(虽然它在方式间的分摊不可识别,见 §6)。

## 5. 灰带 🟡:识别得了但弱 / 与别的参数共线(这是 limitation,不是 finding)

- **收入档拆分**(⚠ 2026-06-08 已弃用,换教育档,见 §5.5;以下为历史收入版,房价代理矛盾):γ_M/α_W/ν_D 都按低/中/高三档各一套,但收入档是出发地的**软占比广播**(房价代理 + soft mixture),
  不是硬标签。要把三档分开,得靠"不同出发地的档构成不同 → 目的地模式不同",信号很弱。
  - 证据:全量 γ_M = [0.41/**0.83**/0.62],**中档最高**反直觉(低/高反而低);三档 profile span 对比 **[g_split]**。
  - 这解释了从伦敦带过来的"中等收入 γ 反直觉":根源是**档拆分弱识别**,模型在三档间能较自由地折中,不是真发现。
- **α_W / ν_D 与 γ_M 共线**:工资(房价面)、竞争(residents/jobs)、岗位三个面空间高度相关,
  目的地效用里它们部分可互相替代。各自 span 不为 0(**[alpha_mid]** / **[nu_mid]**,识别得了),
  但中档 ν_D 出现异常大负值([-0.45]甚至[-1.13])= 与 γ_M 折中的共线印记。

> 写论文要点:🟡 这一档**单独声明为 limitation**——档级异质性的具体数值别过度解读,只看符号和量级方向。

## 5.5 人群异质性:实现到什么程度(2026-06-09,教育档)

⚠ **维度变更**:收入档(§5 上文)2026-06-08 弃用(房价代理矛盾;CFPS 收入矩 n=110、低≈中=二元噪声)→ 换 **教育档**(2015 普查真三档 n≈9.5k,通勤 [20.8/33.6/44.4]min,三档两两 t>12 极显著)。下面是现行教育档的异质性现状。

异质性**结构**是 first-class 搭进去的(参数按档/职业/方式各分一套),但"**真异质性**"分两类:

**① 实现了(外部数据锚得住的维度)**:
| 异质维度 | 状态 | 实现方式 |
|---|---|---|
| 通勤忍受度 × 教育档 | ✅ **真异质** | `T_max=[42/64/95]`min,跨 seed std<1min,锚到普查真三档梯度 |
| 职业 → 去向 | ✅ **真异质**(二阶) | typed-mass `M_j^o` + 跨区条件 logit δ=0.86(蓝领→工业/白领→科技) |
| 方式选择 | ✅ 锚定 | nested logit per-mode + 份额锚 [.21/.35/.44] |

**② 没实现(聚合 OD 钉不住)**:
- **档间偏好参数 β_t(时间敏感)/α_W(工资敏感)三档基本平** —— 一个档只有一条通勤时间矩(3 个数),钉不住 ~15 个档级参数;**不声称档间偏好差异**。
- ν_D 档间只可信**符号**(教育版 -0.015~-0.027,比收入版 -1.13 温和,但量级仍不报)。

**③ ⭐ 最根本的诚实边界 —— 这是"区级人群构成"异质性,不是"个体级"**:
- 模型只有出发地的**档构成比**(`education_tier_props`,16 区广播到格),看不到个体标签。
- 能说:"高教育占比高的区,通勤/去向模式如何" ✅;
- 不能说:"同一起点,高教育个体 vs 低教育个体的选择差异" ❌(需个体级数据,北京红线挡)。
- **档间偏好参数识别不出** 与 **异质性只到区级构成** 是**同一个根**(生态推断)。

> 写论文:实现的异质性 = **外部数据锚定的、区级构成层面的**(通勤忍受度按教育 + 去向按职业),真实、可解释、可外推;个体级/自由估计的偏好异质性聚合 OD 做不到,诚实写 limitation。这跟"可解释 + 可外推优先"自洽:**锚定的异质性恰恰是能外推的那种**(高教育耐远 95min 有行为含义、可传导反事实),自由估计的个体异质性才是难外推的黑箱。

## 6. 🟠 mode:聚合 OD 识别不出,靠双锚联合估计救

北京手机信令 OD 是**方式合并**的——只记"多少人 A→B",不记"谁坐什么"。

**诊断**:`profile_mode_reopt.py` 固定 `asc_transit` 扫值重训其余,OD-NLL span 仅 **0.035**
(对应 P(transit) 从 0.01 到 0.82 给同样拟合)→ 不可识别。方式内部 asc/β_t/θ_inc 的分解更是没救。

**解法**(Ben-Akiva & Morikawa 1990 联合估计精神,从外部带标签数据注入):
- **去向锚**(`--anchor-transit`):公交刷卡 10.6M 出行 → 格子级 transit OD(含地铁)。
  模型预测公交流量分布对齐刷卡 transit OD 分布(CE)。
- **份额锚**(`--anchor-share`):北京真实通勤方式分担(2015 1% 微观个体 M61:车 0.21 / 公交 0.35 / 步+自行车 0.44)。
  模型流量加权方式份额对齐此目标(CE)。
- 实现:锚在 200 万边采样上算(脱离全局归一,兼容 origin-chunking → 任意 GPU)。

**结果**:全量 3-seed,**mode split [0.21/0.35/0.44] 全部锚到真实值**
(s0[.214/.352/.435] / s1[.217/.347/.435] / s2[.212/.347/.441])。
mode 从"识别不出/随初值漂"变为"数据锚定到真实通勤分担"。λ≈0.56(三 seed 0.59/0.55/0.53),
落在 (0,1) 中间 = 方式内部真有相关(对比伦敦 λ≈0.97 嵌套退化)。

## 7. 🔴 occupation:最彻底识别不出,typed-mass 重参数化 + 金标准实证

### 7.1 诊断:span 0.00004,比 mode 还彻底
`profile_occ_reopt.py` 固定 `delta_match` 取 0~8、重训其余,OD-NLL span 仅 **0.00004**
(δ 取啥拟合零变)→ 最彻底不可识别。根因:match 来自区级(出发地+目的地都区级)→ 近常数(mean 0.98 std 0.03),
δ·match 没有结构通道(不像 mode 经 IV 进可达性)。

### 7.2 重参数化:引力作用在"本职业岗位"
不把 occupation 当独立旋钮 δ,而是让引力直接作用在**本职业的岗位** M_j^o = 总岗位 × 该地职业需求占比:

  V_dest(职业 o) = γ · log(M_j^o) + α·log W_j + ν·log D_j + λ·IV

微观个体数据(2015 1% 跨区通勤者)条件 logit 验证 **δ ≈ γ**(0.86 vs 0.99),即"typed-mass 单系数"
比"总引力 + δ 修正"少一参数、拟合一样 → 数据支持重参数化,**δ 的识别难题在此 formulation 下消失**。

### 7.3 finer-geo:让 M_j^o 表达职业集聚
- **2008 经普**(24 万企业,街道 + 行业)→ 街道级行业 → 格子级行业构成。
  - ⚠ 2008 用 GB/T 4754-**2002**,与 2011 版同字母含义不同(F/G/H/I);按**语义**对齐(经业务文字反推),非字母位置。
- **2023 AOI** 校准 post-2008 集聚(望京信息业 0.027→0.049 翻倍);AOI 稀疏故影响有限(L1 0.086)。
- 结果:海淀(中关村)专技 0.40 > 朝阳(望京)0.32 > 大兴(亦庄)0.24(生产运输 0.32)—— 真实职业集聚被捕获。

### 7.4 诚实结论:occupation 匹配是二阶效应(金标准实证)
2015 微观(职业×居住区×工作区,北京就业 9938 人)直接测:
- 不控居住时,各职业"工作区分布"相关 0.376(看着不同);
- **控制居住区后相关 0.976**(几乎相同)→ 那 0.376 几乎全是**居住分选**(不同职业住不同区 + 就近上班),
  职业本身不独立预测去向。条件 logit 估 δ=0.86 但对数似然增益仅 0.6%(统计显著、经济二阶)。
- 细到职业中类无增益:**天花板是工作地地理分辨率(微观只到区/县),不是职业不够细**。

> 北京 occupation 匹配真实存在(蓝领→亦庄工业 / 白领→中关村·金融街),但**二阶**;
> 引力(住哪 + 岗位在哪)是主力。模型把它建成"按职业的岗位引力 γ≈0.98"是正确且可解释的。

## 8. ⚪ NN:预测识别,不是结构识别(初版没区分的一类)

`w_nn·V_NN` 残差与上面的 RUM 系数是**两种不同的识别概念**:
- RUM 系数(γ/β/λ…)是**结构识别**——有曲率就有唯一可解释最优,可代入文献符号。
- NN(w_nn + GraphSAGE encoder 数千参数)是**预测识别**——只识别到"它给 CPC 加了多少",
  靠 ablation 量(关掉掉 CPC),不识别到可解释的结构;靠低维嵌入(emb=16)+ 残差约束(w_nn≈0.09)正则。

写论文不能把 NN 的 w_nn≈0.09 当"NN 不重要"——那是 scale 比值;真实重要性看 ablation drop。

## 9. 全量结果:完整识别模型,零 CPC 代价

RTX 4090(24GB,origin-chunks=16),完整模型 = mode 双锚 + typed-mass occupation + NN(residual)+ 词典筛选 + soc 混合:

| | CPC(3-seed) | mode split | 说明 |
|---|---|---|---|
| 无锚无 typed(基线) | 0.6925 | 不可信(随初值) | — |
| **完整识别模型** | **0.6926 ± 0.0083** | **[0.21/0.35/0.44] 锚定** | mode 识别 + occupation typed-mass 零代价 |

把两个"致命"行为参数都做成数据锚定、可解释的形式,**CPC 一点没掉**。可信度的提升不以拟合为代价。

## 10. 诚实的数据边界(限制章节)

- **mode 份额/去向是锚出来的不是估的**:可写"与真实一致",不能写"模型独立预测"。改 mode 激励的反事实(新地铁/拥堵收费)不能直接信。
- **公交时间**:刷卡实测速度标定(13.4 km/h,含地铁),非逐对路由;β_公交 把"无地铁+车内时间高估"吸进去了。
- **occupation 工作地**:微观只到区/县级 → 区级下匹配二阶;亚区级集聚(中关村等)由 finer-geo **标定**(2008+AOI),非聚合 OD 验证。
- **收入档异质性弱识别**:档级 γ/α/ν 数值别过度解读(见 §5)。
- **时效**:2008 经普(AOI 部分补 2023)、2015 微观 vs 模型 2023 信令,有时间差。

这些边界是数据受限环境(北京红线)下诚实建模的一部分,本身构成方法论贡献:
**聚合 OD 能识别什么(🟢)、什么外部数据救什么(🟠)、哪里只能标定+区间(🔴)、哪里弱识别只看方向(🟡)。**
