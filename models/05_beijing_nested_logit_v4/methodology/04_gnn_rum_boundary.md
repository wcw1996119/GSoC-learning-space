# 北京 v4:GNN 与 RUM 的边界 —— 按"可外推性(因果)"划,不是按"参数 vs 网络"划

(2026-06-07。本文记录混合结构-ML 选择模型(ST-GNN + RUM)最核心的设计原则:两部分各自解释什么、
边界划在哪。是对 [01_identifiability]/[03_AB_coupling] 三个反复出现问题的统一诊断与解法。)

## 0. 一句话核心

**混合模型里,GNN 和 RUM 的边界必须按"谁可以外推(因果)"来划,而不是按"谁是公式、谁是网络"来划:
RUM 拥有因果杠杆并外推(反事实靠它),NN 只做分布内的关联修正、且不外推政策杠杆。
原始设计是"两者共享所有特征 + NN 无约束"——分布内强,但 OOD 崩、可识别性糊。这是病根。**

## 1. 问题:原始设计没有清晰边界

原始 v4 的组合是 `V_dest = V_RUM(θ) + w_nn · V_NN(φ)`,其中:
- **RUM**:参数化结构效用(引力 γ_M·log M、工资 α_W·log W、竞争 ν_D·log D、嵌套 logit β_t/λ、忍受度 T_max、词典筛选)。
- **NN(V_NN)**:GraphSAGE + 双路(静态空间 / 动态时空)+ bilinear,输入节点特征 `Xnode`。

**边界是怎么(没)定的:**
- RUM 是"有符号约束 + 文献锚定"的参数部分;
- NN 是**"残差"——凡 RUM 结构解释不了的都归它**(London 代码原话:"any spatial/temporal pattern RUM doesn't structurally encode")。

这是**负向定义**(剩下的),不是正向定义(具体解释什么)。更糟:**`Xnode` 里含 log_M / log_W / log_D ——
跟 RUM 用的是同一批变量**。于是 NN 可以把 RUM 已经解释的东西(岗位引力)**再非线性地解释一遍** → 两者重叠、抢。

## 2. 一个根,三个问题

边界不清这一个根,长出三个反复撞的问题:

| 问题 | 怎么由"边界不清"造成 |
|---|---|
| **可识别性糊** | NN 重新解释岗位/工资/竞争 → 抢走 γ_M/α_W/ν_D 的可识别性(Fisher 软方向) |
| **反事实崩** | NN 看着岗位 → 干预(加岗位)时它的输入 OOD → 乱外推 |
| **不可解释** | 说不清"RUM 解释 X、NN 解释 Y"——因为它们没分开 |

"绕过岗位"(特征分工)那个补丁,本质是**事后划这条本该一开始划清的边界**。

## 3. 实证:边界不清如何毁掉反事实(总规疏解 CV)

反事实场景 = 北京总规超大城市疏解(通州副中心 +30万岗位 / 核心区 -20%),跨 3 个等价 seed(都 CPC~0.69)测散布:

| 模型 | 通州涌入 CV | 核心区疏解 CV | 结论 |
|---|---|---|---|
| **全模型(RUM+NN)** | **236%**(连方向都反:s0 -2.9% / s1 +4.2%) | 114% | ❌ 不可用 |
| **RUM-only(冻 NN)** | **3.9%**(全 +9~10%) | 4.0% | ✅ 可用 |

> **CV 从 200%+ 暴跌到 ~4%。** 锤实了:全模型反事实崩,是 NN 在 OOD 干预下乱外推造成的;
> 把外推交给 RUM(结构)、不让 NN 碰政策杠杆,反事实立刻稳。
> 同时印证:**反事实稳不稳,看"它依赖的机制(引力)稳不稳",不是"单个参数识别得准不准"**——
> 收入档参数再软,引力驱动的疏解反事实照样稳。
>
> **第三条路(nn-monotonic,见 §5 B)**:NN 不冻、但把它对岗位的响应掰单调,外推方向同样被锁住、散布收敛——
> 即"不砍 NN 也能稳"。确切 CV 当时 print 未存盘,此表 nn-monotonic 行待重跑补。

## 4. 正解:按"可外推性(因果)"划边界

| | 该负责 | 反事实里 |
|---|---|---|
| **RUM = 因果/结构机制** | 有理论的、要干预的变量(岗位/引力、时间/方式、距离) | ✅ **外推**(反事实靠它) |
| **NN = 关联性残差结构** | 没干净理论的、干预下不变的(空间位置、路网拓扑、邻居残差、时空动态) | ❌ **不外推**(只做分布内修正) |

- **RUM 答**:"动了某个因,果会怎样"(可外推、可解释、可识别)。
- **NN 答**:"分布内还有哪些关联模式能提升拟合"(不外推、不解释、提 CPC)。

边界一旦按此划清,§2 三个问题同时缓解。

## 5. 两种"焊死边界"的哲学(待选 / 待验)

| | 怎么划 | 保住 GNN 捕捉岗位非线性? | 反事实可信 | 状态 |
|---|---|---|---|---|
| **A 不相交(干净)** | 因果杠杆全归 RUM;NN 看其余(特征不重叠) | ❌ 放弃岗位溢出 | ✅ 天生(NN 看不到岗位,无法外推) | 代码就绪(`--nn-exclude-jobs`),待重训验证 |
| **B 共享但有纪律** | 两者都碰岗位,但**约束 NN 对岗位的响应(单调/形状)**使其外推因果一致 | ✅ **全保留** | ✅ 需约束 | **推理期地基已实现并验证**(scenario `--nn-monotonic`);训练期内生约束待做 |

- **A** = 拿"NN 对岗位的捕捉能力"换"反事实天生干净"。最直接、可解释。代价:丢岗位集聚溢出。
- **B** = 不砍 GNN,给它的岗位响应上单调/形状约束 → 保住捕捉 + 外推方向对。更难,但是"不砍 GNN 还可信"的真目标。
  - **现状(2026-06-09 校正)**:`scenario_beijing_dispersal.py --nn-monotonic` 已实现**推理期**的单调投影——
    干预时把 NN 对岗位变化的响应掰单调(涨岗位格增量 relu≥0 / 减岗位格 ≤0 / 不变格按 `--mono-spillover` 旋钮放行)。
    跑总规疏解外推:方向被锁住(全模型那种 s0 -2.9%/s1 +4.2% 的翻转不再可能),散布收敛、外推稳定(机制上等价于 RUM-only 的方向一致性,但 **NN 与岗位非线性全保留**)。
    ⚠ 诚实:① 这是**推理期投影**,GNN 仍是无约束训练出来的——**训练期把单调焊进架构**才是 B 的完整体,待做;
    ② 当时确切 CV 是 print 到屏幕的,**没存盘**;§3 表只抄了全模型/RUM-only 两行,nn-monotonic 行需重跑才能补确切数值。
- **原始设计 = 第三种:共享 + 无纪律**(NN 看所有、无约束)→ 分布内强,OOD 崩,识别性糊。**修法是选一种纪律,不是砍 GNN。**

## 6. 与 Shenhao Wang 的区别(贡献定位)

Wang(TB-ResNet)用 δ 凸组合 `(1-δ)V_RUM + δV_NN` **控制比例**,目的是**别让 NN 吞掉 RUM 的可解释性**——
是"**分布内行为参数(弹性/VOT)可信**",**不是 OOD 反事实**。控比例让 RUM 参数不被吞,但**管不住 NN 在 OOD 上乱外推**(比例小 ≠ 方向对)。

> **本工作的边界原则 —— 按可外推性划、用特征分工/形状约束控制 NN 外推 —— 是 Wang 没做的那一层:
> 把"可信深度选择模型"从"分布内参数可信"推到"OOD 反事实可信"。** 这是核心贡献。

## 7. 一句话写进 paper

> 混合结构-ML 选择模型的可信度,关键不在"注入多少理论",而在**边界划在哪**:
> 按可外推性(因果)划——RUM 拥有因果杠杆并外推,NN 做分布内关联修正且不外推政策杠杆——
> 组合模型才同时**可识别、可反事实、可解释**。证据:总规疏解反事实 CV 从全模型 236% 降到边界划清后 ~4%。
