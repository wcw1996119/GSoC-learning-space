# v2 模型方法学速览（大白话版）

## 1. 这个模型在做什么？

我们把伦敦切成 1km × 1km 的小方格（grid），每个方格就是一个"地方"。模型回答这样一个问题：**每个小时，从哪里有多少人通勤到哪里去？** 我们可以问"如果把 5 万个工作岗位加到 X 这个方格里会怎样？"——模型会重新算出新的通勤分布（哪些人改去 X，哪些路段会更堵，平均通勤时间怎么变）。这就是"假设性"（counterfactual）预测。

## 2. 模型的两个零件

模型由两部分拼起来：

- **GNN（图神经网络）**：负责学每个方格"对上班族有多吸引人"。它看每个方格的就业、产业类型、POI、人口、地铁站数量等输入，再看周围方格的情况（图结构传消息），输出一个"吸引力分数" V_j(t)，每小时一个值。
- **RUM 公式（离散选择模型）**：把"吸引力 V_j" 减去"通勤要花的时间成本 β·t_ij"，再过一个 softmax，得到"住在 i 的人选 j 当工作地的概率"。这是经济学里 50 年的经典做法（McFadden 1974）。

简单说：**GNN 学吸引力，RUM 把吸引力和通勤代价组合成选择概率。**

## 3. 反事实预测怎么做？

三步走：

1. 改输入：比如把通州那个方格的"就业岗位数"从 2 万改成 7 万。
2. GNN 重算：新的输入喂给训练好的 GNN，它输出新的吸引力 V_j(t)。
3. RUM 重算：用新的 V_j 套回选择公式，得到新的通勤分布。

整个过程是 forward inference，不需要重新训练。

## 4. 可信度的三层证据

模型预测出来的数字，到底信几分？我们用三个角度查：

- **多远（plausibility）**：你扰动后的输入，离训练时见过的数据有多远？太远（OOD）就只信方向，不信具体数字。
- **多大才合理（magnitude scan）**：把扰动从小到大扫一遍（+5 万、+10 万、+50 万…），看预测变化是不是平滑、单调；如果中间出现跳变或 U 型，说明模型在那个 magnitude 已经不可靠了。
- **多模型对照（cross-check）**：同一个反事实场景，让 gravity / 纯 RUM / GNN+RUM 三个模型都跑一遍，看它们方向是否一致。三个一致 → 可信；分歧 → 只能说"探索性结果"。

## 5. 当前能信什么、不能信什么

可以信：
- **方向**：增加岗位 → 通勤模式会朝哪边变（变多 / 变少）。
- **训练分布内的扰动**：比如 +5 万 ~ +20 万岗位这种"伦敦正常 grid 见过的"量级，可以给点估计。

不要信：
- **极端 magnitude**：单个方格 +100 万岗位之类的，远超训练分布，只看方向。
- **小时级 OD 细节**：因为我们没有真的 hourly OD 数据，hourly target 是合成的，所以小时层面的细颗粒预测只能 aggregate 验证。

**重要 framing**：伦敦只是开发沙盒（pipeline 走通用），**论文实证用的是北京**。伦敦的反事实结果不进论文。

## 6. 跟 v1 的关系

v1 是 HF Spaces 上已经部署的简单 demo（MSOA + 固定 mode + 无 GNN），起公开展示作用；v2 是真正的研究工具（1km 网格 + GNN + RUM + 反事实评估），用来写论文。两者并行，v1 不动。
