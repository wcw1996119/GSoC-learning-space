Joint inverse-recovery of behavioural primitives from aggregate hourly OD, with destination-side BPR closure for counterfactual deployment.
Input · static
Xstatic ∈ ℝN×22
POI (office, retail, F&B), sectoral employment ×8, population, IMD income decile, distance to nearest tube — time-invariant per grid.
Input · dynamic
Xdyn ∈ ℝT×N×5
Hourly congestion z, hourly destination-inflow z, queue residual placeholder, sin/cos hour-of-day. T = 24.
Input · graph + cost
𝒢 = (V, E) — 1 km grid 4-neighbour adjacency
tij(m) ∈ ℝN×N, m ∈ {car, transit, walk}
log dij, πm(i, j), πk(i), OccMatch Distance-aware choice set: walk active only when d < 5 km.
① Static branch
GraphSAGE × 2 layers over time-invariant features.
Computed once per forward pass (no temporal axis).
Output: hs ∈ ℝN×32
② Dynamic branch (per-hour SAGE → GRU + multi-scale TCN)
For each hour t: GraphSAGE × 2 → stack to (T, N, hidden).
Then GRU along T (sequential memory) + parallel multi-scale TCN (kernel widths 3 / 5 / 7, circular padding for 24-h cycle).
Output: hd ∈ ℝT×N×32
hs, hd
③ Gated fusion → Vj,t
Per (t, j) sigmoid gate decides static vs dynamic dominance, then a linear head maps fused hidden to a scalar destination utility.
gate(t, j) = σ(Wg [hs ⊕ hd])    hfused = gate · hs + (1 − gate) · hd    Vj,t = Wv hfused  then  V ← (V − μV) / σV
Output: Vj,t ∈ ℝT×N, z-normalised so α (= 1, fixed) need not absorb scale — cleanly identifies β.
Vj,t
④ Behavioural choice layer — mode × tier mixture RUM
Per-(mode m, tier k) systematic utility, then mixture over the pair-level mode share πm(i, j) and origin tier share πk(i):
Uij,t(m,k) = α Vj,t + βt,m · κk · tij(m) + γ log dij + δk OccMatchij
P(j | i, t) = ∑m πm(i, j) ∑k πk(i) · softmaxj U(m,k)
Recovered (this London run, mean over hours): βcar = −0.187, βtransit = −0.105, βwalk = −0.049, γ = −0.325, κ = [1, 1.98, 1.98], δk = [0, 0.20, 0.20]. Walk identifiable on d < 5 km only (distance-aware choice set).
P(j | i, t) ∇L   ↑
⑤ Cross-entropy loss · multinomial NLL on observed Fij,t
Over all valid (origin i, hour t), cross-entropy of model probability against observed flow distribution. Backprop updates encoder weights Θenc and behavioural parameters jointly.
ℒ = − ∑i, t ∑j Fij,t log P(j | i, t)   +   weight-decay regularisation
Adam: encoder lr 1e−3, RUM lr 1e−2, weight decay 1e−4. Early stop on val NLL with patience 30. 200 epochs / ~80 min on CPU. Final CPC = 0.488.
Trained parameters Θenc (≈ 33 k weights) · βt,m · γ · δk · κk   (frozen at deployment — no re-fit)
Identification. Training uses free-flow tij(m) throughout, so βt,m is the sensitivity of utility to free-flow time. At deployment the same βt,m is applied with congested tij,t(car), eq from BPR. Avoiding flow ↔ time simultaneity in the inverse loop preserves MLE asymptotics for β; substitution at deployment is consistent under the single-component invariance assumption (Schölkopf et al., 2021).
