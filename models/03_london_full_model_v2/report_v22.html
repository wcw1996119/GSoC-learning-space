7. Limitations (still honest)

  • α_occ = 0.228, not 1.0 as supervisor would prefer — softplus + prior keeps it positive but data still pulls it small. Calibration on NTS individual-level data (when ethics clears) should help.
  • 10k agent downsample — scaling to 100k would reduce micro-effect noise.
  • Equilibrium iterates only twice (1 BPR update). Real fixed-point convergence needs 5+ iters with damping.
  • F_ij^t synthesized via Census × NTS, not real hourly observation.
  • Mode is fixed-sampled at agent init, not chosen per trip — nested logit (mode × destination) is v2.3.
