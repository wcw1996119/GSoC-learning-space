1. Architecture: 4-Step Pipeline

Step 1 — Spatial-Temporal GNN Encoder

GAT × 2 + GRU on 1km grid (1725 nodes, kNN(K=10) directed graph + 3-dim edge features). Outputs V_j(t) — destination attractiveness per hour.
Status: trained 30 epochs; loss 17.76 → 16.50.

Step 2 — Workplace Choice (ABM with NN-utility prior)

10,000 synthetic CommuterAgents from 1,581 home grids. Each has SOC occupation (Census 2021), income_tier, age_band, mode_initial, departure_hour (sampled from NTS).
Per-agent utility: V_ij = α·V_j(t) + α_occ·OccMatch_ij − β·t_ij(t) − γ·log d_ij + b where OccMatch_ij = cos(SOC_affinity_vector, dest_industry_mix). Each agent samples workplace ~ softmax(V_ij).
Status: trained linear utility (5 params), CPC val 0.241 (beats single-GNN 0.226).

Step 3 — Emergent congestion

Aggregate agent flows per (origin, destination, hour). BPR formula uses 95th-percentile inflow as capacity proxy. Multiplier capped at 2.5×.
Status: implemented; congestion shifts mean commute time ~10% across iterations.

Step 4 — Multi-stage calibration

Stage 1: encoder OD reconstruction (already done in v2 STGNN training). Stage 2: choice model NLL with frozen encoder (linear utility on aggregate F_ij^t). Stage 3: scalar calibration (BPR α/β capped, β fixed from WebTAG VOT).
Status: Stage 1+2 done; Stage 3 manual not yet automated grid search.

4. Methodology Honesty (Limitations)

  • Linear utility, not full NN — for v2.1 baseline, NN-utility was OOM-prone on full 1725×1725 grid. Linear works; NN upgrade is v2.2.
  • OccMatch coefficient is near-zero / slightly negative — the hand-coded SOC × sector affinity matrix may not match the data. Calibration on LTDS/NTS individual-level data would help (currently aggregate only).
  • Mode is fixed-sampled at agent init, not chosen per trip. Mode choice (nested logit) is v2.2.
  • Income heterogeneity in β not yet implemented. Per memory, this is v2.1+ extension.
  • 10k agents is a downsample from 5M+ real London commuters. Scaling up would reduce sampling noise.
  • Synthesized hourly OD (Census × NTS) is not real observation.
  • Equilibrium is approximate (1 BPR update + 1 re-sample, no iteration to true convergence).
