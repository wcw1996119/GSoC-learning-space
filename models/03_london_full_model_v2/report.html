5. 当前 limitation（要在论文标）

  • F_ij^t 是合成的：用 NTS aggregate × Census OD，不是真 hourly 观测
  • OA→MSOA21 lookup 用了 2011 lookup：约 10% OA 失配 → London 总人口 7.8M（实际 ~9M）
  • Borough congestion 太粗：同 borough 所有 grid 共享同一拥堵率
  • NTS 仅 commute purpose × hour，不区分 mode（车/公交/步行）
  • β=0.07 固定，learned ablation 还没做
  • Edge feature 简化为 3 维，没加 subway-direct flag + mode availability mask
  • 训练只 30 epoch，没看到 plateau
  • UI 没做，目前只有 CLI
